# 🐶 SoyPerritoProProYT Bed

Un juego web de bloques inspirado en la idea de Minecraft Bedrock, creado para SoyPerritoProProYT.

## 🎮 Funciones actuales
- 🌍 Mundo de bloques jugable en navegador.
- 🐶 Personaje SoyPerrito.
- 🎨 Selector de skins.
- 📥 Importación de skins PNG/JPG.
- ✨ Opción de skin por capas preparada para 4D.
- 📱 Controles táctiles para móvil y TV con navegador.
- ⌨️ WASD + espacio para teclado.
- 🖱️ Clic izquierdo/derecho para acciones.
- 🎮 Detección de mandos mediante Gamepad API.
- 💾 Skin importada guardada en el navegador.
- 📐 Diseño adaptable a móvil, PC y pantallas grandes.
